# Schattenvorstand

Dieses Angular-Projekt dient als Grundlage für eine kleine Webseite des Schattenvorstands.

Es handelt sich um eine humorvolle Weise eine Gruppe vorzustellen und hat keinen besonderen nutzen.

## Voraussetzungen

- [Angular CLI](https://angular.io/)

## Installation

```bash
npm install
```

### Lokale Entwicklung

```bash
ng serve
```

Anschließend im Browser öffnen unter: [`http://localhost:4200`](http://localhost:4200)

### Bauen

```bash
ng build
```

Das Build wird im Ordner `/dist/` abgelegt.

## Deployment

Dieses Projekt soll mit GitHub Pages deployed werden.

```bash
npm run gh-build
npm run gh-deploy
```
